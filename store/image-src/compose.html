Private by design

PopShield makes its decisions inside your browser.

No browsing history

PopShield keeps no browsing history. The only site names it saves are the ones you choose a mode for; everything else is an anonymous count.

No telemetry

No analytics, no account, no background network requests. Details go to GitHub only if you press Report and confirm.

No remote code or lists

All logic ships inside the extension. It does not download filter lists or scripts.

Open source

Every line is public on GitHub, so you can check exactly what it does.
